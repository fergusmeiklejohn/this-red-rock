# Testing Nested Blog Structure

This is an example blog post that demonstrates how we can organize blog posts in nested folders. The URL for this post will be `/experiment-1/blog-1` instead of the previous `/blog/experiment-1/blog-1`.

## Benefits of Nested Structure

1. **Better Organization**: Group related posts together in folders
2. **Cleaner URLs**: Remove the redundant `/blog` prefix
3. **Scalability**: Easier to manage large numbers of posts

## How It Works

The blog post is stored at:
```
src/content/blog/experiment-1/blog-1.md
```

And is accessible at the URL:
```
https://this-red-rock.com/experiment-1/blog-1
```

This structure allows for creating series of posts, experiments, or any other logical grouping you need.
